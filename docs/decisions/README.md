# Design Decisions (ADR)

이 프로젝트에서 실제로 고민하고 선택한 기술적 결정들을 기록합니다.

각 문서는 다음 구조를 따릅니다.

- **문제**: 어떤 상황/제약이 있었는가
- **검토한 대안**: 무엇과 비교했는가
- **결정**: 무엇을 선택했는가
- **결과/트레이드오프**: 선택으로 인해 얻은 것과 포기한 것
